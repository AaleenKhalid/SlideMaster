### This is my Final Year Project Repository
The purpose of this project is to create an application that utilises the power of AI to generate content for a slide deck from a user prompt. 
This tool aims to streamline the process and reduce the overall time taken to produce slide decks. 
Users will have the option to export the generated content to Google Slides, further easing the creation process.

### How this application works
This application presents a prompt to the user to outline their requirements for the content to be generated.
Once the prompt has been successfully filled, a call is made to an LLM. Gemini was used for this application.
Upon receiving the generated content, the application performs some simple fact-checking and verification.
The content is then presented to the user in 2 versions: raw markdown format and annotated HTML, marking the verification results.
The user is presented with the option of exporting the generated content to Google Slides
